# IOT-based-Smart-Dustbin
## Project Description

The IoT-Based Smart Dustbin is a smart waste-management system developed using NodeMCU ESP8266. The system automatically detects waste, identifies wet and dry waste using a soil moisture sensor, detects harmful gases using a gas sensor, and provides alerts using a buzzer. A servo motor is used for automatic dustbin lid operation.

## Objectives

- To detect waste and monitor the dustbin level automatically.
- To identify wet and dry waste using a soil moisture sensor.
- To detect harmful or foul gases generated by waste.
- To open the dustbin lid automatically using a servo motor.
- To provide an alert when the dustbin is full or gas levels are high.
- To promote proper waste segregation and smart waste management.

##  Working

1. The ultrasonic sensor detects the presence of waste and monitors the waste level.
2. When a person approaches the dustbin, the servo motor automatically opens the lid.
3. The soil moisture sensor detects the moisture content of the waste.
4. If moisture is detected, the waste is classified as wet waste.
5. If moisture is not detected, the waste is classified as dry waste.
6. The waste can then be directed to the respective wet or dry compartment using a mechanical partition.
7. The gas sensor monitors harmful or foul gases produced by waste.
8. If the gas level becomes high, the buzzer provides an alert.
9. When the dustbin reaches the specified level, the buzzer can also indicate that the bin needs to be emptied.
10. NodeMCU ESP8266 acts as the main controller and coordinates all sensors and output devices.

###  Working Flow

**Waste Detection → Lid Opens → Moisture Detection → Wet/Dry Identification → Waste Separation → Gas Monitoring → Alert**
